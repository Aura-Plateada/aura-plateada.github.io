# Silververso - Sitio Web Oficial

Página web del **Silververso** creado por **Aura-Plateada**

## 🌟 Acerca del Sitio

Este repositorio contiene el sitio web oficial del Silververso, un universo de ficción que incluye múltiples proyectos, comics, juegos de rol y narrativas interconectadas.

### ✨ Características
- **Optimizado para GitHub Pages**: Solo incluye archivos esenciales referenciados en HTML
- **Tamaño reducido**: 50MB vs 1.59GB del repositorio completo
- **Enlaces actualizados**: Todos los enlaces de imágenes y recursos corregidos
- **Responsive**: Diseño adaptativo con Bootstrap 5.3.0

### 📁 Contenido Incluido
- **Páginas principales**: index.html, proyectos.html, sobremi.html, contacto.html
- **Proyecto Centinela**: Sistema completo con comics, personajes y mapas
- **Portadas de proyectos**: GT-01 a GT-49 con imágenes representativas
- **Recursos web**: CSS, imágenes y assets necesarios

### 🚀 Despliegue
Este sitio está configurado para funcionar perfectamente en GitHub Pages.
